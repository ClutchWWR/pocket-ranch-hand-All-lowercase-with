Pocket Ranch Hand — first Android-friendly prototype

OPEN NOW: Download index.html and open it in Chrome on Android, or extract the ZIP and open index.html. Save/search/edit/delete and backup work locally in a compatible browser.

VOICE: Android Chrome may support browser speech recognition, but recognition from file:// pages may be restricted. For best results, host the ZIP contents on an HTTPS static site (free hosting is possible). Microphone permission is required. Speech recognition may use an online provider and is not guaranteed to work offline.

INSTALL AS AN APP: To install using 'Add to Home Screen', host files together on HTTPS. The service worker is not registered when opened as a local file.

DATA: Stored in localStorage of the browser/origin. Clearing browser storage can delete entries; use Backup my list regularly. Data does not sync between devices. Photos are resized, but browser storage is limited. Backup JSON includes photos and should be kept private.

This is a prototype, not a Play Store app. No paid AI or cloud database is required for typed save/search.
